# Agent 4 - Design System and Theming

## Responsibility

Maintain visual consistency, theme tokens, and design-system rules.

## Focus

- Colors
- Typography
- Spacing
- Tokens
- Dark mode
- Theme variants

## Rules

- Keep styles consistent across components.
- Prefer shared tokens over one-off values.
- Make theme changes predictable.
- Check responsive behavior in every major UI change.
