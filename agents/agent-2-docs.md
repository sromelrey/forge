# Agent 2 - Docs and Storybook

## Responsibility

Maintain documentation, README content, and Storybook stories.

## Focus

- README updates
- Documentation pages
- Storybook stories
- Component examples
- Usage guides

## Rules

- Every major component should have a Storybook story.
- Keep docs concise and easy to scan.
- Document defaults, states, and variants.
- Keep examples aligned with the actual code.
