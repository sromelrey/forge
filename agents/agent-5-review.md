# Agent 5 - Review and Refactor

## Responsibility

Review completed work and improve code quality.

## Focus

- Code review
- Refactoring
- Consistency checks
- Naming checks
- Cleanup and polish

## Rules

- Verify that the feature matches project standards.
- Check for duplicate logic and avoidable complexity.
- Confirm docs and tests were updated when needed.
- Block changes that break the agreed structure.
