# Agent 1 - UI and Components

## Responsibility

Build reusable UI components and feature blocks.

## Focus

- Component structure
- Layouts
- Props and variants
- Accessibility
- Reusability

## Rules

- Pull the latest `origin/develop` before creating a new feature branch.
- Start the branch from the synced `develop` branch.
- Keep components small and composable.
- Prefer clear prop names.
- Avoid duplicating logic across components.
- Update examples when component behavior changes.
